# ROS2 远程驾驶上位机操作说明

本文档说明 Qt 远程驾驶上位机的启动、连接、手动驾驶、视频查看、JSON 回放和安全操作。
适用于当前仓库中的 `ros2_viewer` 程序。

## 1. 使用前准备

运行前确认：

- ROS 2 车辆节点或 WebSocket-ROS 2 桥接节点已经启动，并监听 WebSocket 服务端口。
- 已知 WebSocket 地址，默认是 `ws://127.0.0.1:8770`。
- 如果需要视频，WebRTC 页面服务已经启动，默认地址是 `http://127.0.0.1:8080`。
- 如果使用手动控制，Xbox 手柄已连接到运行上位机的计算机。
- 已确认车辆处于安全测试环境，急停装置可用。

上位机只通过 WebSocket 与 ROS 侧通信，不会自动启动 ROS 节点或车辆底盘节点。

## 2. 编译和启动

在项目目录执行：

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/ros2_viewer
```

依赖 Qt6 Widgets、Qt6 WebSockets、Qt6 WebEngineWidgets、CMake、Ninja、GCC 和 SDL2。

启动后主窗口标题为“ROS2 远程驾驶上位机”。手柄会在程序启动时初始化，界面每 50 ms
轮询一次手柄状态。

## 3. 界面区域

### 顶部连接栏

- **WebSocket**：填写 ROS 桥接节点的 WebSocket 地址。
- **连接**：建立 WebSocket 连接。
- **断开**：发送停止指令后断开连接。
- **WebRTC 页面**：填写视频页面地址。
- **加载视频**：在中间的视频区域打开该页面。

### 左侧“控制与连接”

- **连接状态**：显示未连接、正在连接、已连接、连接断开或正在重连。
- **单向延迟**：根据心跳响应估算的单向网络延迟。
- **输入设备**：显示检测到的第一个 Xbox 手柄名称。
- **Xbox 输入**：显示当前转向、油门、刹车和档位数值。
- **控制模式**：选择“手动控制”或“JSON 回放”。
- **打开回放 JSON / 开始回放 / 停止回放**：管理本地回放文件。
- **急停**：触发或解除急停锁存。

### 中间区域

- **WebRTC 视频**：显示视频页面及加载结果。
- **二维运动轨迹**：根据收到的车辆状态显示 `x`、`y` 和 `yaw` 轨迹。

### 右侧“状态与安全”

- **小车状态**：显示位置、航向角、速度和电池电压。
- **绿灯 / 红灯**：交通灯状态开关。红灯状态会禁止油门并发送刹车。

## 4. 建立连接

1. 先启动 ROS 侧 WebSocket 服务端。
2. 在顶部 **WebSocket** 输入框填写地址，例如 `ws://192.168.1.20:8770`。
3. 点击 **连接**。
4. 确认左侧连接状态变为“已连接”。连接成功后，Qt 每秒发送一次 `ping`，服务端应返回
   `pong`；否则单向延迟不会更新。
5. 服务端发送车辆状态后，右侧数值和中间轨迹会自动刷新。

连接断开后，Qt 会停止心跳并自动尝试每 2 秒重连。车辆侧仍必须实现控制超时保护，不能
仅依赖上位机重连。

## 5. 手动控制

### 选择手动模式

将 **控制模式** 设置为“手动控制”。切换模式时上位机会先发送一次停止指令；手动模式下
“打开回放 JSON”和“开始回放”按钮不可用，“停止回放”仍可用于发送停止指令。

### Xbox 手柄映射

| 手柄操作 | 上位机指令 |
| --- | --- |
| 左摇杆左右 | 转向，归一化范围 `-1.0` 到 `1.0` |
| 右扳机（RT） | 油门，范围 `0.0` 到 `1.0` |
| 左扳机（LT） | 刹车，范围 `0.0` 到 `1.0` |
| A 键 | 档位 `1` |
| B 键 | 档位 `-1` |
| Y 键 | 档位 `0` |
| Back 键 | 触发急停 |

档位会保持最后一次按键设置，直到再次按 A、B 或 Y。左摇杆有约 8% 的死区，避免摇杆
轻微漂移造成车辆动作。

手动控制约每 50 ms 发送一次。只有检测到手柄且未触发急停时，控制消息的 `enable` 才会
为 `true`。

## 6. 交通灯和急停

### 交通灯

- 点击右侧按钮可在绿灯和红灯之间切换。
- 红灯时，上位机会立即停止回放，并发送 `throttle: 0`、`brake: 1`、`enable: false`。
- ROS 侧发送状态消息中的 `traffic: "red"` 或 `"stop"` 时，界面也会切换到红灯。
- 收到 `traffic: "green"` 时，界面恢复绿灯显示。

交通灯只是上位机的一层保护，车辆底盘节点仍应在 ROS 侧独立执行安全限制。

### 急停

1. 点击左侧 **急停**，按钮文字变为“解除急停”，并立即发送停止指令。
2. 急停期间，手动和回放指令都会被替换为安全停止指令。
3. 确认环境安全后，再点击“解除急停”。解除后不会自动恢复油门，需要重新操作手柄或
   重新开始回放。
4. 也可以按 Xbox 手柄的 Back 键触发急停；解除急停需点击界面按钮。

如果 WebSocket 已经意外断开，停止指令可能无法送达；车辆 ROS 节点必须设置通信超时并
自动刹车。

## 7. JSON 回放

### 准备文件

回放文件是本地 JSON 数组，每项包含时间和控制值：

```json
[
  {"t_ms": 0, "steer": 0.0, "throttle": 0.2, "brake": 0.0, "gear": 1},
  {"t_ms": 1000, "steer": 0.3, "throttle": 0.2, "brake": 0.0, "gear": 1},
  {"t_ms": 2500, "steer": 0.0, "throttle": 0.0, "brake": 1.0, "gear": 0}
]
```

要求：

- 文件顶层必须是 JSON 数组。
- 数组每项必须是 JSON 对象。
- `t_ms` 为从回放开始计算的毫秒数，必须大于或等于 0，并按非递减顺序排列。
- `steer`、`throttle`、`brake` 的取值范围分别为 `[-1, 1]`、`[0, 1]`、`[0, 1]`。
- `gear` 为整数。

### 回放步骤

1. 确认 WebSocket 已连接。
2. 将 **控制模式** 切换为“JSON 回放”。
3. 点击 **打开回放 JSON**，选择回放文件。
4. 确认界面显示“已加载 N 条”。如果文件无效，状态栏会显示错误原因。
5. 确认急停已解除后，点击 **开始回放**。
6. 回放过程中可以点击 **停止回放**；停止后上位机会发送刹车指令。
7. 回放完成后，上位机会自动发送停止指令，左侧显示“回放完成”。

急停锁存或未连接 WebSocket 时，点击“开始回放”不会启动，并会在状态栏提示原因。
切换控制模式也会先发送停止指令。

## 8. 断开和退出

正常结束操作时：

1. 先松开手柄油门，或点击 **停止回放**。
2. 确认车辆已停止。
3. 点击顶部 **断开**。程序会先尝试发送停止指令，再关闭 WebSocket。
4. 再关闭 Qt 窗口。

## 9. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 一直显示“正在连接”或“连接断开” | 检查 ROS 桥接节点是否启动、IP/端口是否正确，以及防火墙设置 |
| 显示“WebSocket 地址无效” | 地址应包含协议和主机，例如 `ws://127.0.0.1:8770` |
| 输入设备显示“未检测到手柄” | 检查手柄连接、SDL2 权限和系统是否识别为游戏控制器 |
| 视频区域加载失败 | 确认 WebRTC HTTP 服务已启动，地址可在浏览器访问 |
| 回放文件无法加载 | 检查 JSON 语法、顶层数组和 `t_ms` 顺序 |
| 单向延迟一直为 `-- ms` | 检查服务端是否对每个 `ping` 返回相同时间戳的 `pong` |
| 界面有状态但车辆不动作 | 检查 `enable`、档位、ROS 控制 topic 映射和车辆侧安全状态 |

详细 JSON 字段和 WebSocket 协议见 [通信格式.md](通信格式.md)。
